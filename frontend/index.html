About the Project

This classification system is trained on the legendary UCI Cleveland Heart Disease dataset. By mapping 13 core physiological features (including cholesterol, resting blood pressure, chest pain classification, and ST slope segmentations), the system trains classification algorithms like Logistic Regression, Random Forests, and SVMs. The highest-performing model is loaded to process prediction requests.

Educational Screening Disclaimer: This application is for educational, research, and general screening purposes. It has not been clinically validated. It does not provide medical diagnoses, treatment paths, or professional clinical guidelines.
